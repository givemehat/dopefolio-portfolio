Project Overview

Engineered the Quantum Dissipative Market Simulator (QDMS), a platform leveraging Qiskit and QuTiP to model market crashes as open quantum systems using the Lindblad Master Equation. This sophisticated system integrates a FastAPI backend, advanced predictive machine learning models (e.g., LSTM and XGBoost), and a dynamic React 19-based dashboard, enabling real-time visualization of quantum states and liquidity collapses.
