## 🌟 About This Repository

This repository contains the source code for my personal developer portfolio, showcasing my journey, research, and technical projects in **Artificial Intelligence, Machine Learning, and Quantum Computing**.

### Key Highlights:
- **Responsive Design**: Mobile-first architecture ensures a seamless experience across all devices.
- **Dynamic Projects Showcase**: Features custom AI-generated abstract thumbnails for all case studies and research papers.
- **Autonomous SEO**: Powered by a background GitHub Action AI Agent (`self_repair_agent.yml`) that actively monitors HTML health, corrects broken links, and optimizes Alt tags daily.
- **Formspree Integration**: Contact form submissions are seamlessly routed directly to my email.

## 🛠️ Built With

- **HTML5 & CSS3** (SASS/SCSS for styling)
- **Vanilla JavaScript** (ES6+)
- **GitHub Actions** (CI/CD for deployment and Autonomous AI SEO maintenance)
- **GitHub Pages** (Hosting)
